# Multi-Modal AI
## See, Hear, and Understand — All at Once

Build AI that processes text, images, audio, and video in a single unified pipeline.

**Live:** https://multi-modal-ai.vercel.app

---

## What This Demonstrates

### Unified AI Pipeline
- Text + Image + Audio + Video
- Single model, multiple modalities
- Cross-modal understanding

### Real-world Applications
- Image captioning with context
- Video summarization
- Audio transcription with analysis
- Multi-modal search

---

## Getting Started

```bash
git clone https://github.com/cyber-lazer-mermicorn/multi-modal-ai.git
cd multi-modal-ai
npm install
npm run dev
```

---

## Modalities

| Modality | Model | Task |
|----------|-------|------|
| Text | GPT-4 | Understanding & Generation |
| Image | DALL-E 3 | Generation & Analysis |
| Audio | Whisper | Transcription & Analysis |
| Video | Sora | Generation & Summary |
